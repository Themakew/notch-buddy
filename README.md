# NotchBuddy

This repository is the public home for NotchBuddy support information.

Its purpose is intentionally small:

- Publish the NotchBuddy privacy policy.
- Collect feature requests through GitHub Issues.

## Privacy

Read the privacy policy here:

[PRIVACY.md](PRIVACY.md)

## Feature Requests

Have an idea for NotchBuddy? Please open a GitHub Issue and describe:

- The feature you would like to see.
- Why it would be useful.
- Any examples, screenshots, or workflows that help explain the request.

Please keep requests focused on the app experience. Bug reports and support questions can also be opened as issues if they help clarify a feature or improvement.

## App

NotchBuddy is a macOS app. This repository does not contain the application source code.
